# proxemics_points.py

## Purpose
Utility script for calculating scale-adjusted proxemics distance points.

## Description
Scale-based proxemics calculation that generates 6 evenly-spaced distance points (0.46 to 1.5 meters) scaled by a factor of 0.05 (or configurable).

## Code Overview
- Generates 6 evenly spaced points between 0.46 and 1.5 meters
- Applies a scale factor (default 0.05) to adjust for coordinate system
- Outputs original and scaled points</content>
