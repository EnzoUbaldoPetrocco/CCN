One Way ANOVA test, using F distribution df(1,79) (right tailed)

1. H0 hypothesis
Since p-value<α, H0 is rejected.
Some of the groups' averages consider to be not equal.
In other words, the difference between the sample averages of some groups is big enough to be statistically significant.

2. P-value
p-value equals 0.000680993, [p( x ≤ F ) = 0.999319 ]. It means that the chance of type1 error (rejecting a correct H0) is small: 0.000681 (0.068%)
The smaller the p-value the stronger it support H1

3. The statistics
The test statistic F equals 12.509713, which is not in the 95% region of acceptance: [0 : 3.9619]

4. Effect size
The observed effect size f is large (0.4). That indicates that the magnitude of the difference between the averages is large.
The η2 equals 0.14. It means that the group explains 13.7% of the variance from the average (similar to R2 in the linear regression)
