1. H0 hypothesis
Since p-value > α, H0 is accepted.
The averages of all groups assumed to be equal.
In other words, the difference between the sample averages of all groups is not big enough to be statistically significant.

2. P-value
p-value equals 0.895324, [p( x ≤ F ) = 0.104676 ]. It means that if we would reject H0, the chance of type1 error (rejecting a correct H0) would be too high: 0.8953 (89.53%)
The bigger the p-value the stronger it supports H0

3. The statistics
The test statistic F equals 0.0174227, which is in the 95% region of acceptance: [0 : 3.9619]

4. Effect size
The observed effect size f is small (0.015). That indicates that the magnitude of the difference between the averages is small.
The η2 equals 0.00022. It means that the group explains 0.02% of the variance from the average (similar to R2 in the linear regression)

5. Tukey HSD / Tukey Kramer
There is no significant difference between the means of any pair.
