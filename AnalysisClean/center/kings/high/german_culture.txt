1. H0 hypothesis
Since the p-value < α, H0 is rejected.
Some of the groups' averages consider to be not equal.
In other words, the sample difference between the averages of some groups is big enough to be statistically significant.
2. P-value
The p-value equals 0.003573, ( P(x≤6.0297) = 0.9964 ). It means that the chance of type I error (rejecting a correct H0) is small: 0.003573 (0.36%). The smaller the p-value the more it supports H1.

Sphericity
Sphericity is the assumption for equality of variances of the differences between the groups.
Greenhouse-Geisser ε=0.8821, Huynh-Feldt ε=0.9178, Lower-bounde ε=0.5.
Mauchly's test of sphericity indicated that the assumption of sphericity can not be rejected, hence the assumption had not been violated, χ2(2) = 5.884, p = .053, w = 0.866


If you won't correct the significance level (α) and all the comparisons are independent, then the type I error may get to 0.1426. 1 - (1- 0.05)3 = 0.1426.
This is the worse case, since usually some aspects of the multiple tests are in common, and the type I error will be lower.
In this case, the Bonferroni correction would be an overcorrection and would reduce the test power.
The corrected α using the the Bonferroni correction method is 0.01667.
m - the number of tests / pairs.
Corrected α = α / m = 0.05 / 3 = 0.01667.
