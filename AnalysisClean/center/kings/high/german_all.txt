If you won't correct the significance level (α) and all the comparisons are independent, then the type I error may get to 0.1426. 1 - (1- 0.05)3 = 0.1426.
This is the worse case, since usually some aspects of the multiple tests are in common, and the type I error will be lower.
In this case, the Bonferroni correction would be an overcorrection and would reduce the test power.
The corrected α using the the Bonferroni correction method is 0.01667.
m - the number of tests / pairs.
Corrected α = α / m = 0.05 / 3 = 0.01667.
